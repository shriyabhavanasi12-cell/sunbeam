A little corner of the internet I created for myself.

Sunbeam is a personal website built as a creative coding project. It brings together a bright aesthetic, interactive elements, and a welcoming experience designed around the idea of making everyday moments  of my life a little more special.

##  Features

- **Personalised Experience:** An interactive experience created for personal use.
- **Minimal Interface:** A clean, bright and welcoming design.
- **Interactive Elements:** Designed to make navigating the website engaging.

## How to Use

1. Visit [Sunbeam](https://sunbeam-bay.vercel.app/).
2. Click on **"Begin My Perfect Day "** to get started.
3. Follow the on-screen interactions to explore the experience.

languages used: html,css , javascript

 Run Locally

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project directory:

cd sunbeam

Open index.html in your browser.
